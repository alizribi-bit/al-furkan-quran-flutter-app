## ✨ الميزات الرئيسية

1. **عرض المصحف الكتابي المتدفق (Flowing Mushaf Book Page)**
   - عرض الآيات كصفحة مصحف حقيقية متصلة ومضبوطة الهوامش (Justified RTL) بخط **مجمع الملك فهد العثماني (`KFGQPC Uthmanic`)** وفواصل الآيات المزخرفة `﴿١﴾`، لتقوية الذاكرة البصرية المكانية لمواقع الآيات.
   - **حجب مكاني ذكي بـ 3 مستويات** (`ظاهر` / `مموه` / `مخفي`) يحافظ على مواضع السطور والآيات داخل الصفحة مع إمكانية **النقر للتلصص المؤقت (2.5 ثانية)** على أي آية منفردة.
2. **محرك الحلقة الذهبية المتقنة (4-Phase Golden Loop)**
   - **المرحلة (أ) التثبيت الفردي**: تكرار كل آية مع مهلة صمت للترديد الذاتي.
   - **المرحلة (ب) الربط التراكمي**: ربط الآيات تصاعدياً مع تمييز سلسلة الربط داخل الصفحة.
   - **المرحلة (جـ) الإحكام والدمج**: تلاوة المقطع متصلاً لترسيخ السياق.
   - **المرحلة (د) التسميع النشط**: حجب النص وكتم الصوت للاسترجاع الذاتي غيباً.
3. **مكتبة القراء المعتمدين (24+ قارئاً · 4 روايات)**
   - **حفص عن عاصم** · **ورش عن نافع** · **قالون عن نافع** · **الدوري عن أبي عمرو**.
4. **أرشيف الموارد المرجعية (`reference_archive/`)**
   - يضم كافة الملفات القيمة المستخلصة من المشروع السابق (جداول الأحزاب والأرباع والركوعات، نصوص التجويد، ووثائق البحث العلمي) موثقة بالكامل في `reference_archive/LEGACY_INVENTORY.md`.

## 🚀 التشغيل المباشر (Clean Standalone Root)

هذا المستودع هو مشروع Flutter نظيف ومباشر في الجذر (بدون أي تطبيقات متداخلة):

```bash
git clone https://github.com/alizribi-bit/al-furkan-quran-flutter-app.git
cd al-furkan-quran-flutter-app
flutter pub get
flutter run
```

لبناء حزمة أندرويد APK:
```bash
flutter build apk --release
```

## 🗺️ خارطة الطريق المرحلية
- ✅ **المرحلة 1**: تنظيف المستودع وأرشفة الموارد + تخطيط صفحة المصحف الكتابي المتدفق مع الحجب المكاني التفاعلي.
- ✅ **المرحلة 2**: قسم المتون العلمية (**تحفة الأطفال** كاملةً ٦١ بيتاً بـ ٧ أصوات و**متن الشاطبية** بـ ٤ أصوات ودليل الرموز) بـ ٣ أنماط عرض (**الديوان الشعري**، **الدراسة والشرح**، **الحفظ والتسميع**).
- ✅ **المرحلة 3**: مكتبة **الأناشيد الإسلامية الصوتية (بدون إيقاع ولا موسيقى)** مع مختارات موثقة، موسوعات مفتوحة (+٢٬١٠٠ نشيد) وبحث حر مباشر عبر واجهة Internet Archive API المجانية مع المفضلة ومؤقت النوم.
