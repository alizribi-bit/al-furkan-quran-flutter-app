## 🌟 مستجدات التحديث الأخير (Latest Updates)

تم تحديث المستودع بالكامل ليشمل أحدث التقنيات البيداغوجية والعلمية في حفظ القرآن الكريم:
1. **محرك الحلقة الذهبية المتقنة (The 4-Phase Golden Loop)**:
   - **المرحلة (أ) التثبيت الفردي**: تكرار كل آية منفردة $N$ مرات مع فترة صمت محتسبة لترديد الحافظ بصوته.
   - **المرحلة (ب) الربط التراكمي (الأسلوب العثماني)**: ربط الآيات تصاعدياً ($1 \rightarrow 2$، ثم $1 \rightarrow 2 \rightarrow 3$، ...) بعدد $L$ مرات لتمتين الانتقالات البينية.
   - **المرحلة (جـ) الإحكام والدمج النهائي**: تلاوة المقطع كاملاً متصلاً كوحدة واحدة وتكراره $M$ مرات لترسيخ السياق في الذاكرة طويلة المدى.
   - **المرحلة (د) التسميع النشط (Active Recall Test)**: كتم الصوت تماماً، وحجب النص القرآني تدريجياً، مع مسجل صوتي مدمج للاسترجاع الذاتي.
2. **مكتبة «القارئ المعتمد» (24+ قارئاً بروابط CDN موثوقة)**:
   - تغطية 4 روايات متواترة: **حفص عن عاصم**، **ورش عن نافع**، **قالون عن نافع**، و**الدوري عن أبي عمرو**.
   - ربط مباشر بسيرفرات السحابة الصوتية المعتمدة (`EveryAyah` و `MP3Quran` عبر `verse.mp3quran.net`).
3. **هوية بصرية جديدة كلياً (Itqan Quran)**:
   - أيقونة فاخرة بهندسة الـ Squircle وتذهيب المصحف الشريف والزخارف الأندلسية.
   - حزم أيقونات أندرويد الرسمية (Mipmap) لجميع كثافات الشاشات (`res/mipmap-*`).
4. **تحسينات تجربة المستخدم (UX Ergonomics)**:
   - إدخال الأرقام مباشرة من لوحة المفاتيح دون الحاجة للنقر المتكرر.
   - شرائح تكرار سريعة بنقرة واحدة: `[3×]`، `[5×]`، `[7×]`، `[10×]`.
   - شريط تقدم بصري تفاعلي ومؤشرات واضحة للمراحل.

## 📂 بنية المستودع (Project Structure)

يحتوي المستودع على نسختين متكاملتين ومتزامنتين:

```
al-furkan-quran-flutter-app/
├── flutter_app/            # 📱 تطبيق فلاتر المحدث للأجهزة الذكية (Android / iOS)
│   ├── lib/
│   │   ├── core/           # محرك الصوتيات، بيانات القراء الـ24، والتنبيهات
│   │   ├── screens/        # شاشات الحفظ الهادئ (ZenHifz)، الحلقة، والمواقيت
│   │   └── main.dart       # نقطة الانطلاق لتطبيق فلاتر
│   ├── android/            # إعدادات حزمة الأندرويد، الأيقونات والصلاحيات
│   └── pubspec.yaml        # حزم فلاتر (just_audio, hive_ce, livekit, etc.)
│
├── src/                    # 🌐 تطبيق الويب التفاعلي (React + Vite + TypeScript)
│   ├── components/         # مكونات واجهة الحفظ، المشغل، والنافبار
│   ├── services/           # محرك hifzAudioEngine وقواعد بيانات السور
│   └── types/              # تعريفات الأنواع والروايات الأربع
│
├── public/                 # الأيقونات الفكتورية وأرشيف flutter_app.zip المحدث
└── run_flutter.sh          # سكربت تشغيل سريع لتطبيق فلاتر بنقرة واحدة
```

## 🚀 طريقة التشغيل على جهازك المحلي (Local Setup)

### 1. سحب آخر التحديثات من GitHub
افتح موجه الأوامر (Terminal) في حاسوبك ونفذ:

```bash
cd ~/Desktop/quoran/al-furkan-quran-flutter-app

# جلب آخر الفروع والتحديثات
git fetch origin

# التأكد من التواجد على فرع main والتحديث
git checkout main
git pull origin main
```

### 2. تشغيل تطبيق فلاتر (Flutter Mobile App)
تطبيق فلاتر المحدث بكامل ميزاته موجود داخل مجلد `flutter_app/`:

```bash
# الدخول إلى مجلد فلاتر
cd flutter_app

# تثبيت الحزم والمكتبات
flutter pub get

# تشغيل التطبيق على الهاتف أو المحاكي
flutter run
```

*أو يمكنك تشغيله مباشرة من المجلد الرئيسي عبر السكربت المرفق:*
```bash
./run_flutter.sh
```

## 🎙️ قائمة القراء المعتمدين المتوفرين (24 Reciters)

| الرواية | القراء المعتمدون |
|---|---|
| **حفص عن عاصم** | محمود خليل الحصري (معلم ومرتل)، محمد صديق المنشاوي (معلم ومرتل ومجود)، عبد الباسط عبد الصمد (مرتل ومجود)، علي بن عبد الرحمن الحذيفي، عبد الرحمن السديس، سعود الشريم، مشاري راشد العفاسي، سعد الغامدي، ماهر المعيقلي، أبو بكر الشاطري، أيمن سويد |
| **ورش عن نافع** | محمود خليل الحصري، عبد الباسط عبد الصمد، عمر القزابري، ياسين الجزائري |
| **قالون عن نافع** | علي بن عبد الرحمن الحذيفي، محمود خليل الحصري، الدوكالي محمد العالم |
| **الدوري عن أبي عمرو** | مفتاح السلطني، الفاتح محمد الزبير |
